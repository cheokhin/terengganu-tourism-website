# Terengganu Tourism Web Application

## 1. Project Objective
Developed a dynamic, interactive web application dedicated to promoting tourism in Terengganu. The platform highlights local attractions, culinary specialties, and lodging options through an engaging, visually driven user interface.

## 2. Tech Stack
* **Languages:** HTML5, CSS3, JavaScript
* **Design:** Custom CSS Animations, Responsive UI Layouts, Ionicons Integration
* **Deployment:** Hosted live on GitHub Pages

## 3. Core Features & Architecture
* **Live Deployment:** The application is fully deployed and accessible via [GitHub Pages](https://cheokhin.github.io/terengganu-tourism-website/).
* **Dynamic Layouts:** Engineered a structured, multi-page web application featuring dedicated sections for local food, culture, and accommodations.
* **Custom UI Components:** Implemented a JavaScript-driven dynamic "Back to Top" scroll progress indicator alongside smooth-scrolling anchor links for seamless navigation.
* **Separation of Concerns:** Maintained strict architectural standards by decoupling HTML structure from CSS styling and JavaScript logic, ensuring clean, scalable, and maintainable source code.

## 4. Setup & Execution
1. Clone this repository to your local machine.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari) to launch the application locally.
3. Alternatively, view the live production build at: [https://cheokhin.github.io/terengganu-tourism-website/](https://cheokhin.github.io/terengganu-tourism-website/)
